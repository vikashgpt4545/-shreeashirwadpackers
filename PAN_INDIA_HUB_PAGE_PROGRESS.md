## 1. Operating Principles & Architecture

1. **Two-Tier Local Authority Structure**:
   - **Tier 1 (City / Town Authority Hubs)**: `pages/packers-and-movers-in-[city].php` (e.g. `pages/packers-and-movers-in-patna.php`, `pages/packers-and-movers-in-bangalore.php`).

   - Strictly **NO connecting corridor / route pages** ($X \rightarrow Y$) in this track.
2. **Quality & Technical SEO Standards**:
   - Full HTML5 document shell: `<!DOCTYPE html>`, `<head>`, scoped CSS styles, header partial, main content, footer partial.
   - **Word Count**: 1,600 to 2,000+ words of localized relocation information per page.
   - **Schemas**: Exactly 4 valid Google-compliant JSON-LD schemas (`MovingCompany`, `BreadcrumbList`, `Service`, `FAQPage`).
   - **Visuals**: Exactly 3 to 4 authenticated images with constrained responsive cards (`max-width: 680px; margin: 28px auto;`).
   - **Internal Linking**: Pillar link to parent city hub, cluster links to neighboring localities, reciprocal corridors, and transparent tariff calculator link.
   - **Zero PHP Syntax Errors**: Verified with `php -l`.
   - **Live Verification**: 100% HTTP 200 OK verified on server.

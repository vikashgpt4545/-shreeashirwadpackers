## 1. Architectural & Technical Standards (Mandatory Across All 20 Routes)
1. **Word Count**: $\ge 1,500$ visible words of original, highly localized, technically sound relocation copy (target: 1,700–2,300 words).
2. **Visual Assets**: Exactly 4 verified images from `images/` directory:
   - `images/safe-transit-container-truck-ranchi.jpg` (Hero / transit)
   - `images/complete-household-packing-dhanbad.jpg` (5-layer packing)
   - `images/car-transport-carrier-loading-jharkhand.jpg` (Vehicle transport)
   - `images/unpacking-and-setup-service-ranchi.jpg` (Destination setup / unpacking)
3. **Structured Data Schemas (JSON-LD)**: 4 valid schemas per page:
   - `MovingCompany` (with Hazaribagh/destination coordinates, verified phone, address, operating hours)
   - `Service` (with `areaServed` for both cities, detailed route description)
   - `BreadcrumbList` (Home &rarr; Hazaribagh Hub &rarr; Route Page)
   - `FAQPage` (6 in-depth localized route questions with rich answers)
4. **Scoped CSS Design**: Unique CSS class prefix per route (e.g. `h2dhn-`, `h2jsr-`, `h2grd-`, etc.), modern typography (`Plus Jakarta Sans` and `Outfit`), high-contrast accessible color palette, responsive data tables, process cards, and review cards.
5. **SEO Directives**: Meta titles (55–65 characters), Meta descriptions (150–160 characters), canonical URL, geo tags, Open Graph, and Twitter cards.
6. **Zero LaTeX**: Strictly use HTML entities (`&rarr;`, `&ndash;`, `&bull;`, `&#9733;`) instead of raw LaTeX tokens (`$\rightarrow$`).
7. **Institutional Billing**: Full documentation for NTPC North Karanpura, CCL (Central Coalfields Limited Barka-Sayal/Argada/Charhi/Kuju), BSF Meru Camp, Police Academy, Vinoba Bhave University (VBU), banks, and railway transfers.
